About your browser...

If you ended up here, your browser is missing features needed by ASCE Bridge Designer. Sorry about that. We do our best to be compatible with most devices having a mouse or similar gadget and a broad range of browser software.

What's okay...

Not touch-only devices. Sorry. We don't support pure touch screens with no mouse-like pointer.
Many browsers. Up-to-date versions of these should be fine:
  • Based on recent Chromium:
    • Google Chrome
    • Microsoft Edge
    • Chromium, open source
    • Opera
  • Firefox
Other Chromium- and Firefox-based browsers may work fine. Unfortunately, we can't currently support Apple Safari.
Screen resolution. At least 1280 by 720 pixels.
Mouse-like device. An accurate pointer such as a mouse, track pad, or track ball is necessary.

How to fix problems...

Take your chances. ASCE Bridge Designer might be okay with your current setup despite warnings. Some features may be disabled or work poorly. Give it a try by clicking Cancel in the warning dialog.
Adjust settings or hardware. If you were warned about screen resolution or mouse, you'll want to adjust or replace hardware. Pro tips:
  • Screen resolution is often a choice. Check your operating system's display settings. Pick a resolution of 1280x720 or more. Bigger is better.
  • For lower resolutions, set the browser to "full screen mode" to use all possible pixels.
  • Many touch devices support adding a mouse at no or low cost. Check the web for options.
Switch or upgrade your browser. If a startup warning complained about an unsupported browser or missing HTML or CSS features, try installing a current, supported version. If your device is unable, try the latest possible version of Google Chrome. That's the best chance of success.

Help us out

Report problems. If, after reading through all above, things still don't make sense, report a bug via email to the project team.
Software fixes. If you're a developer, we'll happily consider your pull requests to address browser-related bugs and limitations. File a bug or feature request first to discuss what you'd like to do. See the project home page.
